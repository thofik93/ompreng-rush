# Ompreng Rush

Game arcade satire bertema program makan siang gratis. Kamu relawan dapur yang harus melengkapi ompreng pesanan murid, sambil menghadapi efisiensi anggaran, tikus berdasi, lauk kemarin yang dibantah lewat rilis resmi, dan kunjungan pejabat yang bikin menu mendadak mewah.

**Main langsung:** https://thofik93.github.io/ompreng-rush/

## Cara main
- Geser jari atau mouse untuk menggerakkan ompreng. Di keyboard pakai ← → atau A D, dan P untuk pause.
- Tangkap menu sesuai pesanan murid sebelum bar sabarnya habis.
- Hindari 🪰 lalat, 🪨 kerikil, 🦠 lauk kemarin, dan 🐀 tikus berdasi.
- Power-up: 🤝 orang dalam, 📢 viral, 🧋 es teh, ❤️ warga patungan.

Dibuat dengan [Phaser 3](https://phaser.io) (dimuat dari CDN). Arena permainan dirender Phaser, sedangkan HUD dan overlay memakai HTML biasa. Satu file `index.html` tanpa build step: buka langsung di browser atau lewat static server mana pun.

*Satire. Semua lembaga, tokoh, dan berita di game ini fiktif.*
